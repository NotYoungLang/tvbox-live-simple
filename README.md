# tvbox-live-simple

Filtered TVBox live source for MiTV-ASTP0 (Xiaomi TV, Android 9).

## Files
- `live_simple.m3u` - active channel list (188 channels, ads/placeholder lines removed, de-duplicated).
- `live_result.m3u` - full source from Guovin/iptv-api gd branch (backup lines for repair).
- `make_live_simple.py` - regenerate active list from the full source.
- `check_channels.py` - health-check job: probe every line, swap dead ones for a working backup.
- `CHECK_REPORT.md` - latest auto-check report (generated by Actions).
- `验证报告.md` - manual logo verification report (2026-11-21).

## TVBox config address (live source)
`https://gh-proxy.com/https://raw.githubusercontent.com/NotYoungLang/tvbox-live-simple/main/live_simple.m3u?v=2`

(raw.githubusercontent.com direct times out on this TV; gh-proxy prefix required. The `?v=` query bypasses CDN cache.)

## Auto check
GitHub Actions runs `check_channels.py` daily at 00:00 and 12:00 UTC (08:00 / 20:00 Beijing).
It probes all channel URLs, repairs dead lines from same-channel backups, and commits changes.
Can also be triggered manually via Actions -> "Auto check live channels" -> Run workflow.
